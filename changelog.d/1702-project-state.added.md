A Bot that needs `PROJECT.md`, `ROADMAP.md`, `docs/governance.md`, a decision file or `LESSONS.md` can now read it through the `project_state` tool, which lists the Project State files of its working folder with a sha256 content hash, byte size and last-modified time, or returns one file whole up to 200,000 bytes. A missing file, an oversized file and a folder without `.git` each answer with the reason instead of an empty string ([#1702](https://github.com/ThinkFlowLab/FlyBot/issues/1702)).
