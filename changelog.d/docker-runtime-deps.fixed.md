The Docker image now carries the FlyBot core's runtime dependencies. The profile links the packages, and a link installs none of their own dependencies, so a container started healthy but could not open the Feishu long connection (and could not load the Claude or Codex executor SDKs). The build now fails if a declared dependency is missing, and a Feishu connection that fails because the SDK is absent says so in the diagnostics instead of pointing at the network and credentials.
