The Timeline panel now opens on a window it can actually show: `windowMs` from the plugin config was handed to the panel as given, while the panel's own Window control is clamped to 30 s–24 h, so a configured value outside that range left the control with no option to select — a blank selector, a header naming a span the host never serves, and a "Copy report" computed over a window the data did not cover. The config value now goes through the same clamp as the control, whose smallest option is 1 min (24 h at the top, whole milliseconds), and a value that is not a number keeps the documented 15-minute default ([#3366](https://github.com/ThinkFlowLab/FlyBot/issues/3366)).
