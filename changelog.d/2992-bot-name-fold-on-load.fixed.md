A team saved before a Bot name folded its runs of spaces is repaired once when it loads: a stored `Dev  Ops` is read as `Dev Ops`, so `@Dev Ops` now reaches that Bot instead of a twin created afterwards. Creating or renaming to the single-space spelling is refused while the old name is there, and when two saved names fold onto one, the Bot that already held the folded spelling keeps it and a log line names the one that did not. See [#2992](https://github.com/ThinkFlowLab/FlyBot/issues/2992).
