Saving a key no longer lands through a temp name someone else planted: the secrets file is staged at `secrets.json.<pid>.<uuid>.tmp` with an exclusive create, so a link, a hard link or a directory at that name refuses the save before its first byte — nothing is written outside the home and nothing is renamed into place ([#2864](https://github.com/ThinkFlowLab/FlyBot/issues/2864)).
