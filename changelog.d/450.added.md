A tree merge now leaves the Bot that keeps the role a traceable handoff line instead of nothing: after the duplicate is archived, the kept Bot's prompt reads `Inherited from <name> (source <id>, merged <time>): role "…"; N child Bots moved to you; its chat and memory stay on the archived Bot`, and a host that allows the tree in `flybot.memoryPlugins` records the same note in the kept Bot's own memory through the new `flybot.handoff.note` seam (metadata `source: handoff`, `from`, `at`). The archived Bot's chat and memory are only read, never rewritten; undo removes the prompt line, while the memory note stays as the record of the merge ([#450](https://github.com/ThinkFlowLab/FlyBot/issues/450)).
