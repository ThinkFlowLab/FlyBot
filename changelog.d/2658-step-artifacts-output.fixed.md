An issue fast-line run no longer ends `failed` after its pull request was already opened: a Triage step that prints its delivery as its own `OUTPUT pr: 2657 (verified)` — or as `OUTPUT merged: <40-character sha>` — now counts as work done, so the run continues to `gate`/`enqueue`/`attest` and its record keeps the pull request number instead of dying on a missing `state` line ([#2658](https://github.com/ThinkFlowLab/FlyBot/issues/2658)).
