The diagnostics report behind Settings → Feedback's **Report on GitHub** now names the team file itself, right after the table that counts the team: `state file: ~/.dsh/state.json (<size> bytes, last written <ISO UTC>)` for a plain file, `state file: none yet (this computer has not saved the team)` before this computer has one, and `state file: not a plain file (nothing is read or written)` when the path is a directory, a link or a file with a second name. The line is built from `lstat` alone — `state.json` holds the members, the messages and the saved keys, so the report may describe the file and never opens or reads it — and a read-only window draws the same line ([#2394](https://github.com/ThinkFlowLab/FlyBot/issues/2394)).
