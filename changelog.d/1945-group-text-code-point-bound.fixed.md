A group's notice and name are now cut on a code point instead of a UTF-16 unit ([#1945](https://github.com/ThinkFlowLab/FlyBot/issues/1945)): a 2000-unit notice or a 60-unit name that ended in a whole emoji used to store a lone surrogate, which every encoder downstream turned into U+FFFD; the bound now drops the straddling character whole, the way every other cut in the host already did.
