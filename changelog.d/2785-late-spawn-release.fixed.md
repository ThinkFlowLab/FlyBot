`boundedSpawn` released the Bots a late spawn created only when the host’s late answer succeeded: a late **failure** carried the ids it had already made on `error.spawned` and the deadline branch only warned, so those hidden run Bots lived until the process exited. The deadline now releases that list too, while a refusal and a release that itself fails still warn ([#2785](https://github.com/ThinkFlowLab/FlyBot/issues/2785)).
