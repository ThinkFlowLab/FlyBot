A refusal the host sends with no message of its own no longer reaches the screen as a blank error: the client's `api/bot` wrapper answers it with `Request failed`, so a surface that prints the failure says what went wrong instead of drawing nothing — and a Bot's memory row settles on that sentence instead of sitting on `Loading…` ([#2411](https://github.com/ThinkFlowLab/FlyBot/issues/2411)).
