The gate-change signature is now judged by the copy of the checker in the pull request's base commit instead of the copy in its own tree, so a pull request can no longer weaken or delete `policy-sign.mjs` and pass the check it just edited — the `Gate change signature` step still runs before the suite, and a signature is still a comment by someone other than the author that names the head ([#2099](https://github.com/ThinkFlowLab/FlyBot/issues/2099)).
