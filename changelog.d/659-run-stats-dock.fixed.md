On the newer DeepSeek Harness (`0.2.1-alpha.1`) the composer's run-stats footer is no longer a single `stats` entry — the turn and step counts moved into an `activity` pill — so FlyBot's "1 turn" / "1 step" wording stopped replacing the shell's "1 turns 1 steps". FlyBot now wraps whichever counts pill the installed shell publishes, on both versions ([#659](https://github.com/ThinkFlowLab/FlyBot/issues/659)).
