The merge gate now refuses a tip whose only review is a comment from the pull request author's own GitHub account. A PASS from that login counts when the comment header carries `Attestation: <full sha> role=<Bot>` for this tip, the role matches `Written-by`, and the role is not an Owner of the pull request. A review posted by a different GitHub account is unchanged ([#644](https://github.com/ThinkFlowLab/FlyBot/issues/644)).
