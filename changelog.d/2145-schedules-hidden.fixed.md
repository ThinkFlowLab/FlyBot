The Scheduled tasks page and a Bot's scheduled-tasks line no longer answer "No scheduled tasks yet." when the list is only narrow: once a member is signed in, each member sees their own tasks, so a list that dropped another member's rows now says "No scheduled tasks you can see." and adds either that another member's tasks stay hidden (the page) or that you can add one (the line). A list where nothing was hidden, and a host that narrows nothing, keep the plain empty state. ([#2145](https://github.com/ThinkFlowLab/FlyBot/issues/2145))
