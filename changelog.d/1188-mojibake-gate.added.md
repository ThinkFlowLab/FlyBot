A CI scan (`.github/scripts/check-mojibake.mjs`) now fails a pull request whose tracked text files contain U+FFFD — the three bytes `EF BF BD` a lossy decode writes in place of every character it could not read — and names each file with its occurrence and line counts, so the fix reads as "regenerate", not "retype the text". Binary assets are skipped by content (a NUL byte in the first 8 KiB), which is the rule that makes the gate usable at all: decoding the tree instead reports 22 binary files and ~2,065,422 replacement characters on a clean `main`. `AGENTS.md` now says why a file rewritten from an outside source, or regenerated, is re-read as bytes and re-encoded by its generator. See [#1188](https://github.com/ThinkFlowLab/FlyBot/issues/1188).
