Editing only the name of a scheduled task no longer rewrites its repeat: an interval that is not a whole number of minutes, such as 90 seconds, now reads as **Every 90 seconds**, the form holds that exact value in its seconds unit, and saving a task whose repeat was not touched leaves the stored interval alone instead of rounding it to 2 minutes ([#1651](https://github.com/ThinkFlowLab/FlyBot/issues/1651)).
