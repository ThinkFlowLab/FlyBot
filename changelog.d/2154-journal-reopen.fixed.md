The state journal no longer stays stopped for the rest of the run after one failed open or write. The next save asks once more whether it can record again: a folder or file repaired meanwhile resumes recording, appending the change that save carried, while a journal that still refuses stays stopped and that save still lands. The asking is silent, so a refusal is warned once rather than once per save ([#2154](https://github.com/ThinkFlowLab/FlyBot/issues/2154)).
