A plugin the host allows to make a model call can now also get its own default model: `flybot.modelFor` (`{ '<plugin>': '<provider/model>' }`) is used when the call does not name one, so a host can keep a cheap plugin cheap while the rest of the team stays on the team default. A plugin the host did not name is unchanged, a model the call names still wins, and an entry that is not a non-empty string is ignored rather than passed through ([#579](https://github.com/ThinkFlowLab/FlyBot/issues/579)).
