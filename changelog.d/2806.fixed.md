The board's metrics cache no longer holds every five-minute window it has ever answered: a window that is over is dropped on the next write, and the table is capped, so a host that runs for weeks keeps a handful of entries instead of one per window per repository and zone. A hit inside the same window, the five-minute lifetime and every number on the board are unchanged. See [#2806](https://github.com/ThinkFlowLab/FlyBot/issues/2806).
