**Workflow ephemeral node Bot replies no longer leak into persistent Bot chats.** Previously, ephemeral workflow node Bot replies (e.g., Review / Verify / Rework results) could appear as queued `[Reply from …]` messages in Chief or other persistent Bot conversations when deliveries bypassed send middleware (deferred, resumed, retried flags) or after workflow release. The fix expands the `gated()` check in `hooks.js` so ephemeral bot deliveries ALWAYS route through middleware (ensuring `stepResult` advances the workflow), while the workflow send hook denies delivery to persistent Bot chats. Removed ephemeral bots are tombstoned so late replies cannot leak. Ephemeral Bot outputs stay strictly on the workflow run surface. (#1524)
