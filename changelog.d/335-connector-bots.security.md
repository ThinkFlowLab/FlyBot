Connector tools (GitHub, Composio: `mcp__github__*`, `mcp__composio__*`) are now available only to the Bots you turn them on for: a per-Bot switch under Settings → Connectors → **Choose Bots** and in each Bot's settings, off by default. After upgrading every Bot starts off, including ones that used the tools before; turn them on again for the Bots you want. A Bot that is shared with anyone (a grant, a friend's Bot or another person in its room) never gets connector tools, whatever its switch says, and sharing a Bot clears its switches. Composio's session address is no longer kept in `state.json`: only the session id is stored and the address is asked for from Composio at each start, and a leftover address from an older version is removed on start ([#335](https://github.com/ThinkFlowLab/FlyBot/issues/335)). An Agent whose Bot cannot be determined (for example a sub-agent whose parent Session is gone) gets no connector tools, and the tool list follows a person or friend joining or leaving a Bot's room.
