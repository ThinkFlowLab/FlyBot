Connector tools (GitHub, Composio: `mcp__github__*`, `mcp__composio__*`) are now decided per Bot and per turn instead of reaching every Bot and Session, so a friend who reaches one of your Bots cannot use your mail, calendar or repositories through it unless you allow it (the exact rule is in the entry for [#369](https://github.com/ThinkFlowLab/FlyBot/issues/369)). Composio's session address is no longer kept in `state.json`: only the session id is stored and the address is asked for from Composio at each start, and a leftover address from an older version is removed on start ([#335](https://github.com/ThinkFlowLab/FlyBot/issues/335)). An Agent whose Bot cannot be determined (for example a sub-agent whose parent Session is gone) gets no connector tools, and the tool list follows a person or friend joining or leaving a Bot's room.
