`scripts/i18n-usage.mjs` has a third scan ([#3049](https://github.com/ThinkFlowLab/FlyBot/issues/3049)): a copy drawn through a template literal with a `${}` hole (`superseded by ${id}`) is now reported by `--template-draws` instead of being invisible to both i18n checks, with one `{}` per hole, so the fix is one `tr()` key. The draw is counted where copy is read — an `h()` copy attribute or child, a `text:` prop, a copy table value — including a template the reader reaches through a name. The bare-draw and missing-entry counts are unchanged, and each of those reports now ends with one line counting the template draws it cannot judge.
