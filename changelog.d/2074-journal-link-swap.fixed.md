The state journal now asks what its folder and its file are when it writes, not only when the host starts: a `home/journal` folder swapped for a link is refused with one warning and recording stops, and a `state.jsonl` swapped for a link is never written through, instead of silently appending a snapshot into a folder or a file outside the home. The append path refuses the write; the prune path replaces the link with a fresh file in the verified folder, so nothing is written through it ([#2074](https://github.com/ThinkFlowLab/FlyBot/issues/2074)).
