The sandbox preflight now answers for the file policy it is given (`--mode`, or `FLYBOT_SANDBOX_MODE`) instead of assuming `workspace-write`, never reports a `danger-full-access` session as blocked, reports the Windows ACL runner as `unknown` rather than unavailable, and separates "proven blocked" (exit 3) from "cannot tell" (exit 4), so an agent no longer stops shell work on a probe it cannot complete ([#615](https://github.com/ThinkFlowLab/FlyBot/issues/615)).
