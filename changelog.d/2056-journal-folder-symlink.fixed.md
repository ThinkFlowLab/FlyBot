A journal folder that is a symlink now records nothing, instead of letting the host change the permissions of the folder it points at and write the team's state journal there ([#2056](https://github.com/ThinkFlowLab/FlyBot/issues/2056)): the folder that holds `<home>/journal/state.jsonl` must be a real directory, checked before anything is created, permissions changed or written, so a link to a folder outside the home stops recording with one warning the same way any other journal problem does. A real journal folder records exactly as before.
