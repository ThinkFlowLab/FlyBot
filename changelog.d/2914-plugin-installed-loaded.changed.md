The `plugin-runtime` page now says what the three facts on a Settings → Plugins row are: `enabled` is the owner's switch, `installed` is whether this profile carries the package, and `loaded` is whether this start really attached it — so a switch can be on over a package that is absent, and a carried package can be installed without being attached when its switch is off or its start failed. It also records that with no profile to read, or an unreadable one, `installed` is unknown rather than `false`, and that Settings → Plugins turns only an explicit `installed: false` into the "Not installed in this profile." row. See [#2914](https://github.com/ThinkFlowLab/FlyBot/issues/2914).
