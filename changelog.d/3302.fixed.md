A capability's stored transport error masked the values of configured headers, environment variables and command-line flags, but not one carried in the capability's own URL: a transport that may pass its credential only in the address has to use the query, and a server that answers 401 echoes the address it was given, so `https://host/sse?token=sk-live-…` was stored verbatim and printed every turn in the Bot's system prompt and on the settings page. A query pair whose name promises a credential now masks its own value — the same name list and the same six-character floor as the other masks — while the rest of the address and an ordinary pair such as `?limit=50` stay as they are ([#3302](https://github.com/ThinkFlowLab/FlyBot/issues/3302)).
