A room that was already stored as one chat per member no longer shows the same room several times with each member's lines in their own copy: the older rows' sessions are kept as earlier parts of the one chat, so no line is copied, every message reads back word for word and an assistant reply stays an assistant reply; the chat's session is rebound to the handle of the row that survives, so the next line is sent, an open question card moves with the chat, and a room with more than one open card is left for a later round instead of dropping one. See [#2804](https://github.com/ThinkFlowLab/FlyBot/issues/2804).
