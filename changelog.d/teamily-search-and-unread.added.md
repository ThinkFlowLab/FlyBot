The chat search palette now opens with an empty state instead of a prefilled bot list, keeps a close control, and only offers type filters the host can actually apply: All, Chats, Messages, and Commands. Message search still uses loaded turn outlines, and the copy says so instead of claiming every chat or all content. Session row menus and the header overflow can mark a chat unread or clear that local mark; the unread filter follows the change. Mark as Read does not pretend to acknowledge a completion or pending-interaction flag, and there is no @ filter.
