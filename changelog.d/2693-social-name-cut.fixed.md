A friend's Bot or owner display name is now cut on code points at its 60-character bound, so a name whose bound falls inside an emoji keeps the emoji whole instead of being stored as half a surrogate pair that every later UTF-8 write shows as a replacement character; the file names, outbound drafts and error lines the plugin also caps follow the same rule. A name already stored with a lone surrogate keeps that value: this change fixes new values and does not rewrite stored ones ([#2693](https://github.com/ThinkFlowLab/FlyBot/issues/2693)).
