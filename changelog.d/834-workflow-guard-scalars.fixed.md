The live-e2e secret guard now decides whether a step reads the key from the value YAML parses, not from quotes that happen to appear on the line: a plain `run:` where `#` opens a comment no longer counts as a carrier, and a double-quoted value with an escaped quote before `#` (in `run:` and in an `env:` value) is counted again, so a step that really receives the key cannot pass the check ungated ([#834](https://github.com/ThinkFlowLab/FlyBot/issues/834)).
