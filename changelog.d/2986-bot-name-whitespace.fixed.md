A Bot's name now folds a run of whitespace to a single space when it is created or renamed, the way a group's name already did. `Dev  Ops` (two spaces) is stored as `Dev Ops`, so creating or renaming to it while `Dev Ops` exists is refused with the existing sentence instead of leaving two rows that draw the same name and answer `@` only once. A line break is still refused as a line break, not folded. See [#2986](https://github.com/ThinkFlowLab/FlyBot/issues/2986).
