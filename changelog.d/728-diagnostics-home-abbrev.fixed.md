The report behind Settings → About now shortens the whole home it prints, not half of it: a DSH home outside the OS home used to stand in full in the `Read-only` row (a lock held by another dsh, or a team file that could not be read) while the file rows beside it said `~/state.json`. Both folders now become `~` before the sentence's 200 bound is applied, so a long home no longer cuts the reload advice off the end of that row. See [#2944](https://github.com/ThinkFlowLab/FlyBot/issues/2944).
