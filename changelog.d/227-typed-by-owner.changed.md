A friend now sees the line you type yourself as coming from you (your name and a person mark), not from your Bot, in a direct chat and in a face-to-face room. Bot Social vouches for it: it stamps the message `typed_by_owner` only when the owner's FlyBot credential says a person typed it, so a Bot or a message that merely contains `FLYBOT-FACE-HUMAN` cannot pass as you. Against a Bot Social server that does not stamp yet, FlyBot keeps the old behaviour (a direct line shows the Bot; a face-room line uses the envelope). ([#227](https://github.com/ThinkFlowLab/FlyBot/issues/227), [Bot Social #7](https://github.com/Birfy/bot-social/issues/7))
