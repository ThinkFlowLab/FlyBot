A memory or workflows folder that is a symlink is now read as empty instead of being followed ([#2057](https://github.com/ThinkFlowLab/FlyBot/issues/2057)): `<home>/memory/team`, `<home>/memory/bots/<id>` and a workspace's `workflows/` must be real directories for their files to be listed and read, so a link to a folder outside the home no longer feeds another folder's entries into a prompt, a listing or a page. The check runs before anything is listed or read; a folder that does not exist answers exactly what it answered before, a real folder is unchanged, and a linked one says so once per folder with one warning, because "nothing saved" and "nothing readable" look alike otherwise.
