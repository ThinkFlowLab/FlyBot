A connector or MCP server's error no longer reaches the owner's card as U+FFFD ([#2002](https://github.com/ThinkFlowLab/FlyBot/issues/2002)): the 300-unit `reason` in `core/src/host/connectors.js` used a bare `slice`, so a message whose 300th UTF-16 unit landed inside a surrogate pair was stored with a lone high surrogate. It now goes through the shared `cut`, which keeps within the same 300 the longest prefix that stops before a split pair; a message under the bound is stored word for word.
