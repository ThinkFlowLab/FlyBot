Settings → Bot Social now names the whole server in a Check refusal, not only its host: the address keeps its path (and its scheme when it is not `https`), so two servers on one host — `https://social.example/team-b` and `https://social.example/team-c` — no longer produce byte-identical "Could not reach …", redirect, HTTP-status and "did not answer like a Bot Social server" sentences. See [#2975](https://github.com/ThinkFlowLab/FlyBot/issues/2975).
