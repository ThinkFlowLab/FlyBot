The Project Assistant settings — the digest opt-out, the quiet window and the zone — can now be written by the Project's owner from the product: `project-assistant-owner` is dispatched by the host channel and authorization-checked like the other Project writes, so a non-owner gets `bot/forbidden` instead of `Unknown endpoint` ([#1759](https://github.com/ThinkFlowLab/FlyBot/issues/1759)).
