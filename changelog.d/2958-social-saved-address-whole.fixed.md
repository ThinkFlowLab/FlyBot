The saved-server line under Settings → Bot Social names the whole saved address again: the page cut it at 80 characters with no mark, so two addresses that differed only past that point drew the same sentence, and an address the host could not read drew `The server saved here () cannot be used: …`. The address is now drawn whole up to the host's 200-character bound and shortened with a visible `…` only past that, and an empty address leaves the brackets out.
