A start that moves to another server now asks the backup name before it asks the server for a home: the `.bak` copy (`flybot-social.json.<tag>`) is named from the credentials file already on disk, so a link left at that name refuses the start instead of spending a home on the server first and refusing afterwards. A free name still keeps the old server's credentials there, and a refused `.bak` leaves the credentials in use byte for byte ([#2140](https://github.com/ThinkFlowLab/FlyBot/issues/2140)).
