The diagnostics report behind Settings → Feedback's **Report on GitHub** now names the file the state journal records into, beside `state journal:`: `journal file: ~/.dsh/.../state.jsonl (<size> bytes, last written <ISO UTC>)` for a plain file of the host's own, `journal file: none yet` before the first save creates it, and `journal file: not a plain file (nothing is read or written)` when the path is a link or a file with a second name. The line is built from `lstat` alone — the file is never opened or read — so a report can say how large the journal is and when it was written without needing permission to read it, and a host whose journal is off adds no line ([#2388](https://github.com/ThinkFlowLab/FlyBot/issues/2388)).
