A decided meeting whose archived file cannot be read no longer takes the cards of the Project folder's same-named row ([#2061](https://github.com/ThinkFlowLab/FlyBot/issues/2061)): `archivedOf` now answers three mutually exclusive states (`none`, `unreadable`, `read`), so only a record that named no folder at all reaches the legacy card backfill while a record that named a folder keeps its cards off a row of a different folder — the answer no longer depends on the order the meetings happen to be stored in.
