The report behind Settings → About no longer prints one string for two different files: in the normal layout, where the DSH home sits under the OS home, a file inside that home read `~/state.json` exactly like a file at the OS-home root. The outer folder now shortens to `~` first and a home under it keeps the part that tells it apart (`~/.dsh/bot/state.json`), on the `Read-only` row and on the error lines alike. See [#2956](https://github.com/ThinkFlowLab/FlyBot/issues/2956).
