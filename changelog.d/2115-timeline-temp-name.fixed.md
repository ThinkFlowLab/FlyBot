The timeline trace now asks its temporary name before a segment write lands through it: a symbolic or hard link left at `trace-000001.json.tmp`, or a directory, refuses the write with one warning, so a preset name can no longer take the bytes outside the trace folder or put a link where the segment belongs. The segment is neither created nor replaced on a refusal; a missing temp name stays the writer's to create and the plain leftover of a crashed writer is still overwritten.
