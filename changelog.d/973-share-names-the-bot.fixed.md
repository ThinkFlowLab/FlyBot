**Share with a friend** now shows one row per Bot of a friend instead of one row per person: each row is named `Bot (Owner)` with that Bot's handle, and the **Share** click grants to that row's Bot, so the receipt says which Bot got it. Before, a friend with two Bots collapsed to a single row labelled with the person's name while the grant went to whichever Bot was listed first ([#973](https://github.com/ThinkFlowLab/FlyBot/issues/973)).
