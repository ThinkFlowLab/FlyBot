A decision row on the Project board now opens: activating a `decisions/*.md` row (by mouse or keyboard) shows that file's text under the row, and activating it again closes it ([#2041](https://github.com/ThinkFlowLab/FlyBot/issues/2041)) — before this, the board could list 200 decision files and open none of them. The text comes from a new host read that accepts only a name the board's own listing produced, including one past the 200-row cut, so a name like `decisions/../outside.md`, an absolute path, a name one level down or a symlink answers `not listed` without touching the disk; a file over 200,000 bytes answers `too large` rather than being cut, and a row whose file was deleted answers `absent` and stays a row.
