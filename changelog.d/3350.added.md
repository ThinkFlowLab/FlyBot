The diagnostics report now says what **Settings → Models → Test connection** answered for each Bot's model route: the code (`AUTH`, `QUOTA`, `RATE_LIMIT`, …), `passed`, or `not tested`, with the time the test ran. A report copied after a Bot stopped answering names the route that failed instead of leaving a maintainer to ask what the test said — and copying it never sends another model request ([#3350](https://github.com/ThinkFlowLab/FlyBot/issues/3350)).
