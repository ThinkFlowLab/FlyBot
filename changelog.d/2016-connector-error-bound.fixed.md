A connector's failure text no longer stops at 300 units without saying so ([#2016](https://github.com/ThinkFlowLab/FlyBot/issues/2016)): the `reason` stored on the owner's connector card now holds up to 2,000 — the bound another server's own description already uses — and a message that still has to be cut ends with `…` inside that bound, so the card says what it abridged instead of showing a sentence that stops mid-word as the server's whole answer. A message at or under 2,000 is stored word for word.
