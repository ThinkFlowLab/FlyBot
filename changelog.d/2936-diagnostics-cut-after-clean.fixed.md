The bug report's `Read-only` row no longer stops in the middle of a word: the sentence is now abbreviated to `~` first and bounded after, so a long home folder cannot leave a row that ends mid-word with no mark, and a row that really was cut ends with one `…`. A browser log line and its code carry the same mark where they were cut. See [#2936](https://github.com/ThinkFlowLab/FlyBot/issues/2936).
