Dragging a node or dropping a Bot in the flowchart drawer's **Edit** plane no longer rewrites the stored coordinates: in the laid-out plane where parallel branches would overlap, a drag now changes only the graph's structure and the plane says where layout lives (Settings), so a drag that used to move the same node on the Settings canvas no longer does ([#1686](https://github.com/ThinkFlowLab/FlyBot/issues/1686)).
