The read-only Bot overview's model value is now pinned in the three states it can read — the catalog has not loaded yet, the catalog serves the model, and the catalog cannot serve it — so a change that calls every model `not available` before the list arrives, or hides one the catalog cannot serve behind a plain provider name, fails the suite instead of shipping. See [#2901](https://github.com/ThinkFlowLab/FlyBot/issues/2901).
