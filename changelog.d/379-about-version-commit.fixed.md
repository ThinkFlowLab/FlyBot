Settings → About FlyBot now shows the commit a git install runs even when DSH keeps it hoisted: it is read from the profile's `pnpm-lock.yaml` (the `ds-bot` entry), with the old real-path match as the fallback. A 40-hex ref in the install spec (`#<sha40>`) is treated as a commit, not a branch: the version line shows its short SHA, the update row says `Pinned to commit …`, and the page compares with GitHub only when a branch is known ([#379](https://github.com/ThinkFlowLab/FlyBot/issues/379)).
