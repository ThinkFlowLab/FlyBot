The `Used before` buttons and the `Checked` summary on Settings → Bot Social now name a server by its whole address, not just its host: two servers on one host with different paths (`https://social.example/team-b` and `…/team-c`) used to draw the same label, so the page offered two identical buttons for two different servers. The label keeps the path, and keeps the scheme only when it is not `https://`, so a root address still reads `social.example`. See [#2963](https://github.com/ThinkFlowLab/FlyBot/issues/2963).
