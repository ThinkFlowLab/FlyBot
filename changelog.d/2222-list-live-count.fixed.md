A workflow row with live runs now says how many: the number sits beside the dot and is part of the row's accessible name, so a reader who cannot see the colour can tell one running run from five; an idle row draws no dot, no count and no digit. Opening the list in a read-only window no longer sends `workflow/ingest` for every open card — the Project filter still fills, and a writable window still ingests every open card (#2222).
