The Project board's Decisions and Meetings sections drew their empty state in English in a zh window: the line was English prose handed to `t()` as a key, and the folder case was joined at runtime, so no dictionary entry could ever match it. Both sections now carry the empty case as a key with the folder as a parameter, so a zh window reads 决策/会议 empty states in Chinese while an English window reads exactly the sentence it read before; a read that failed still appears as the host's own sentence.
