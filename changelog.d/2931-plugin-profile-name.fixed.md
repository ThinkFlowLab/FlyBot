The Plugins row for a package this profile does not have prints the profile this runtime is in, not a hard-coded `web`: `plugins/list` and `plugins/set` answer the runtime's own `profile` name, and the row falls back to the literal `--profile <profile>` placeholder when a host answers none (a command naming `web` was wrong on Desktop). `plugins/set` also answers the full rows again, so `loaded` and `installed` survive a flip instead of coming back as `undefined` (P-721) ([#2931](https://github.com/ThinkFlowLab/FlyBot/issues/2931)).
