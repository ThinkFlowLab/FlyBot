Message hover, overflow, and right-click menus now share the actions FlyBot can actually run: add a reaction, reply (quote into the composer), copy, and download. User bubbles use the same menu. A locked window hides Reply. Unimplemented items such as Artifacts, translation, forwarding, multi-select, templates, recall, re-edit, message pin, and report are not drawn. Session Pin/Unpin is already a host flag and is also offered in the conversation overflow when that write is allowed.
