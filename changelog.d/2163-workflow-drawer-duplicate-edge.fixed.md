A wire or a reconnect in the workflow drawer that would repeat a pair the graph already lists now adds nothing, instead of committing the duplicate that the host refuses: before, that save failed with `Link A → B is listed twice` and the plane shows only `workflow.edges`, so the drag left no edge, no change and one red line nobody asked for. Reconnecting an edge onto a target its source already reaches now keeps exactly one edge and drops the one that was dragged, and a wire to a Bot that was not connected yet still adds its edge as before ([#2163](https://github.com/ThinkFlowLab/FlyBot/issues/2163)).
