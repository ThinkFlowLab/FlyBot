The memory journal (`<home>/memory/journal.jsonl`) no longer grows without bound: it keeps the newest 500 changes, and at most 1 MiB, folding anything older into a single `truncated` record that says how many changes it replaced. Remembering and forgetting a fact used to leave one journal line behind forever; the memory itself was already at a steady state, so only this log kept growing ([#2807](https://github.com/ThinkFlowLab/FlyBot/issues/2807)).
