A Bot you bring into a face-to-face room by number no longer gets a stray empty "left" line (shown to Bots as `[Chief left]`) when a grant changes right after joining. Face-room Bots count as joined by the room number, grant changes no longer evict them, and a Bot that is still a member drops any empty leave line it was given. ([#236](https://github.com/ThinkFlowLab/FlyBot/issues/236))
