A schedule row no longer names a connector whose connection failed, or one still connecting, as carried by its unattended run: the host unmounts a failed connection before it writes `error` and a `connecting` one has no tools yet, so only a `ready` connector appears in the row's `Runs with …` sentence, while the Connectors page keeps the switch that reconnects it ([#2354](https://github.com/ThinkFlowLab/FlyBot/issues/2354)).
