The diagnostics report no longer says a linked team file is read through the link when the link points at a folder: `readFile` fails on a folder (`EISDIR`), so the store lands in `stuck` and no save ever replaces the name. `state file:` now keeps `not a plain file (nothing is read or written)` for a link to a folder or to nothing, and keeps the read-through-the-link sentence only when the link resolves to a plain file. The target is asked with `stat` for its metadata only — the bytes behind the link are never opened.
