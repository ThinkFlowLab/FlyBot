Settings → Plugins no longer shows a plugin as simply on when its package is missing from this profile: each row now carries `installed` as well as the owner's switch, read from the profile's `dsh.profile.bundles`, so a plugin whose package was never installed reads as not installed instead of drawing an ON switch for a domain the running process does not have. See [#2868](https://github.com/ThinkFlowLab/FlyBot/issues/2868).
