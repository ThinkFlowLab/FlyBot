The saved-server line under Settings → Bot Social now shortens an over-long saved address in the middle instead of cutting it at 200 characters with no mark: a head prefix stays, then a visible `…`, then the last path segment, so two saved servers that differ only in that segment (`…/one` versus `…/two`) no longer read as one sentence. An address within the bound is drawn byte for byte, unchanged. See [#2968](https://github.com/ThinkFlowLab/FlyBot/issues/2968).
