The face-to-face room no longer closes itself a few seconds after `face-start`: one snapshot that lists no peer no longer counts as every other home leaving, so the room ends only when two polls in a row find no other home, or the server sends the leave event. Seats a room has listed are remembered per room, so a dropped peer no longer looks like a room of one ([#1606](https://github.com/ThinkFlowLab/FlyBot/issues/1606)).
