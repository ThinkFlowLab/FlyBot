The tools that resolve a Bot through `findTeamBot` no longer accept a retired one: `message_bot`, `stop_bot`, `update_bot`, `create_group`, `update_group` (`add_members`, `admin`, `task_lead`) and `archive_bot` refuse it with the familiar "No Bot named …" line instead of waking a Bot the owner just put away. `list_bots` and the Bot's readable chat are unchanged ([#1700](https://github.com/ThinkFlowLab/FlyBot/issues/1700)). Other host paths that resolve a Bot by name (task assignee, group `@Name`, capability attach, memory scope) are tracked in [#1709](https://github.com/ThinkFlowLab/FlyBot/issues/1709).
