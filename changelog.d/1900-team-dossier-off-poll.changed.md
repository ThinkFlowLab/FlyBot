The Project board reads the team dossier (personas, memory heads, skills) once when the board opens instead of on every five-second refresh, so an open board no longer pulls about 16 KB of unchanged data per tick ([#1900](https://github.com/ThinkFlowLab/FlyBot/issues/1900)). A dossier read that fails now leaves the board drawn with an empty team area instead of falling back to the empty-project state.
