Settings → Feedback no longer offers **Clear** in a read-only window: Clear truncates the shared `logs/diagnostics.jsonl` on the host, so a window that only reads now leaves that file alone and keeps **Download**, **Show**, **Copy** and **Report on GitHub**. The host refuses `diagnostics-clear` from a reading window with `bot/read-only` instead of erasing the log a bug report is supposed to carry ([#2302](https://github.com/ThinkFlowLab/FlyBot/issues/2302)).
