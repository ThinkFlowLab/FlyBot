Contributor docs now state how a repository path written in inline code is checked: the core suite fails a page under `docs/` that names a `core/`, `plugins/` or `patches/` file that does not exist, and the fix is to point it at the file's current home rather than to delete the backticks ([#2906](https://github.com/ThinkFlowLab/FlyBot/issues/2906), [#2913](https://github.com/ThinkFlowLab/FlyBot/issues/2913)).
