A Workflow now creates its run Bots four at a time instead of one after another, so a six-node line starts in about 20 seconds instead of about 66 and no longer misses the 60-second batch deadline a slow host used to hit ([#3286](https://github.com/ThinkFlowLab/FlyBot/issues/3286)). If the host refuses one node, the line stops asking for new Bots, waits for the ones already in flight, and releases every Bot it did create; the run still maps the graph's nodes to their Bots in the graph's own order.
