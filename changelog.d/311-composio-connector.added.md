Settings → Connectors has a **Composio** row: paste one Composio API key once, pick the apps (Gmail, Google Calendar, Slack, Notion, Linear and more), and every Bot can use them as `mcp__composio__*` tools; Composio shows a sign-in link in the chat the first time a Bot needs an app. The key is kept as a secret that no Bot shell can read and is sent only to Composio. ([#311](https://github.com/ThinkFlowLab/FlyBot/issues/311))
