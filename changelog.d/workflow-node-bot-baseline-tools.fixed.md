Workflow node Bots now inherit all available tools (file/shell tools, GitHub, Composio, and team tools limited by `EPHEMERAL_DENIED_TOOLS`) when no explicit `tools` list is configured, matching the permissions a normal sidebar Bot gets. Previously, nodes with empty or missing `tools` were restricted to `workspace-write` with no connectors, causing 6-7 minute delays when prompts expected GitHub or bash access. An explicit `tools` list still restricts to those tools only.
