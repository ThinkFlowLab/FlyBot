The report behind Settings → About now says which feature plugin is switched off, so a bundle about "Projects is gone" answers "did you turn it off?" by itself: a `Plugins` row after `Read-only` names every switched-off plugin in list order (`project off`, `timeline, project off`) and ends ` (restart pending)` while a switch still differs from what this start loaded. A host with every switch on, or a state with no `flybot.plugins` at all, draws no row and keeps the report exactly as it was. See [#2940](https://github.com/ThinkFlowLab/FlyBot/issues/2940).
