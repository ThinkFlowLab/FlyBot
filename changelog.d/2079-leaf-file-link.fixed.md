`memory/journal.jsonl`, a workspace `workflows/<id>.json` and `workflows/project.json` are asked as files before a write, the way their folders already were: a missing file is created, a plain file is written, and a link or a directory is not written through ([#2079](https://github.com/ThinkFlowLab/FlyBot/issues/2079)). A linked journal file drops that one record with a warning and the memory write still lands; a linked workflow file refuses the save with `workflow/not-a-file` and one warning.
