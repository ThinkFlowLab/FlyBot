The timeline plugin's `exportMs` is capped at 2147483647 ms (about 24.8 days): a larger value was handed to `setInterval`, which silently replaced the delay with 1 ms, so an export interval meant as "effectively never" ran the exporter on every tick and each run filtered the whole trace on the host's event loop. The interval is now clamped to the ceiling with one warning naming the interval in force, so a long interval exports on the deadline it asks for.
