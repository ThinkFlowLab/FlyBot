A `state.json` whose saved room or Bot record is `null` no longer hides the whole team: the file as it was is kept as a `state.json.broken-<stamp>` copy, one warning names `state.json`, the room is folded to an empty member list (an unusable Bot record is dropped), and the repaired team loads and saves. A version-1 file still keeps its `.v1` backup, and a read-only window records the evidence but never writes `state.json`. See [#2755](https://github.com/ThinkFlowLab/FlyBot/issues/2755).
