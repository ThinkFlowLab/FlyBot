Settings → Bot Social shows the Bot Social server FlyBot uses and its connection, and switches to another server without editing `cordis.patch.yml` or restarting ([#337](https://github.com/ThinkFlowLab/FlyBot/issues/337)). The address must be `https://` (`http://` only for localhost), is checked against `<server>/v1/platform` (its features are shown) before anything is saved, and a switch needs a confirm that says a new server is a new identity: friends and sharing stay on the old server, the old credentials file is kept and never deleted, and switching back restores them. A failed switch puts the previous server back. The profile value stays the default; with nothing configured nothing changes. Plugins can add Settings pages through the new `flybot.settings.page` slot.
