A `Verdict:` now counts only when the workstation that claims to have written it signed it: each reviewing workstation holds one Ed25519 private key, its public key sits in `.github/agent/signers.json`, and the gates verify `Signed-by:` / `Nonce:` / `Signature:` offline over the pull request, the full tip SHA, the verdict and the workstation — so a PASS written in a Reviewer's name on the shared account is no longer a conclusion, it is listed as unverified ([#1110](https://github.com/ThinkFlowLab/FlyBot/issues/1110)).
