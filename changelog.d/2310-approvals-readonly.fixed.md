A window that holds the team read-only no longer draws **Retry**, **Reject** or **Approve** on an approval card or on a held reply's bubble in a chat: none of them can succeed there, because the host refuses the decision, so each card keeps the message, who it is for, and says why in the host's own sentence ([#2310](https://github.com/ThinkFlowLab/FlyBot/issues/2310)). A plugin's own approval card is told the window is read-only too, so it can hide its buttons the same way.
