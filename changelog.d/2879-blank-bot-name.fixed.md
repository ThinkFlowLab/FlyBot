A Bot name made only of characters that draw nothing is now refused with **A Bot needs a name**, from the new-Bot form, on creation and on rename alike: the braille pattern blank, the Hangul fillers, the combining grapheme joiner and the other default-ignorable code points survive both `\p{Cf}` and `trim()`, so such a name rendered as an empty name. A name that draws something is unaffected, and a name keeps the characters it was written with. See [#2879](https://github.com/ThinkFlowLab/FlyBot/issues/2879).
