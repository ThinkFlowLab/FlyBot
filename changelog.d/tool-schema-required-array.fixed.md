A strict OpenAI-compatible gateway no longer rejects the whole chat: every tool FlyBot registers now sends an explicit `required` (empty when nothing is mandatory) and `properties` (empty when it takes no parameters), so an argument-less tool such as `bot_schedules` or `list_bots` cannot turn the tool list into `Invalid schema for function 'bot_schedules': null is not of type "array"`. Tools whose schema comes from an MCP server are passed through by DSH and are not covered by this change ([#768](https://github.com/ThinkFlowLab/FlyBot/issues/768)).
