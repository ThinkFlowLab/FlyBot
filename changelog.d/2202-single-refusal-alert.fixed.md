A refused Rename, Delete or Create in the Workflows panel is announced once now: the dialog that holds the host's sentence is the only `role="alert"` for that refusal, and the section no longer draws a second copy behind the mask that a screen reader read out as well. A refusal with no dialog open is still reported once on the page. In the same family, a read-only window no longer prints the host's read-only sentence twice on Settings → Workflow graphs: the Settings header draws it once for every page, so the workflow page drops its own copy (#2202).
