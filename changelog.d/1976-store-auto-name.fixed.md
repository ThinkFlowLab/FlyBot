A restart no longer renames an unnamed group to `You, …` or drops its remote guests ([#1976](https://github.com/ThinkFlowLab/FlyBot/issues/1976)). On load the host compared the stored title with the name computed from the room's people and guests, then wrote a title computed from the member Bots alone: the owner became `You`, every remote guest fell out of the name, and because that name could never match again the file and the group's Session title were rewritten on every boot. Both the comparison and the write now use the one name that sees the room, so a restart migrates an old title once and then leaves it alone.
