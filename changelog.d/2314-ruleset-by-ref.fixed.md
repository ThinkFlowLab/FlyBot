`gate-ruleset` now finds `main`'s ruleset by the ref it governs instead of by its display name, so the live `main merge queue` reads as gated rather than as "main is unprotected": `--check` names the live id and reports drift in both directions (a context the file wants and the ruleset lacks, and a context the ruleset requires and the file does not carry), `--apply` updates that ruleset instead of creating a second one and refuses a body that would drop a live-required context or the `merge_queue` rule before it sends the request, and `--rollback` deletes the same rows it matched. `policy-sign` also names the comments that can sign the tip when it refuses for a missing or stale signature ([#2314](https://github.com/ThinkFlowLab/FlyBot/issues/2314)).
