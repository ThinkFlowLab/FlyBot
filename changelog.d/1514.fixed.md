Settings → Workflow graphs → Edit now draws the Add link panel with the dialog's own form: a 14px section heading, a responsive field grid, a `Pick a node` placeholder in both node selects, and a primary `Add link` button that stays disabled until both ends are chosen. Node handles are smaller and theme-accent, sit beside the connection line instead of on it, and only gain full opacity and a halo on hover, focus or while a wire is dragged; the settings page also injects the workflow stylesheet when it opens without the sidebar section ([#1514](https://github.com/ThinkFlowLab/FlyBot/issues/1514)).
