A scheduled task that hits an approval no longer hangs its turn: when a reminder turn asks for a tool nobody can approve, the request is rejected in place instead of waiting on a card with no one to answer it, the turn ends normally so `state.scheduleRuns` leaves `running` and the next delivery can run, and the Session the run owns gets one visible line naming the tool and saying it was skipped and can be run from the chat or covered by a standing approval. The direction is only hang → denied, never an allow. See [#2818](https://github.com/ThinkFlowLab/FlyBot/issues/2818).
