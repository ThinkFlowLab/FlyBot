A wire on the Settings → Workflows flowchart now says which two cards it joins and can be pointed at: two wires that end at the same port used to be one stroke to the eye and the wire layer was invisible to a pointer and to a screen reader, so a narration that named a hand-off left no way to find that wire on the picture. Each route now carries a 10px transparent hit path of its own, names both ends (`Reviewer → Deployer` — a hover tooltip and an `aria-label` inside a named `Connections` group), and while the pointer is on it that wire is drawn in the accent colour with the others dimmed. Read-only, this only points at a wire; it commits nothing ([#2142](https://github.com/ThinkFlowLab/FlyBot/issues/2142)).
