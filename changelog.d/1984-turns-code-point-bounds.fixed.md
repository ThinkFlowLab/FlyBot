The host's turn lines no longer split a surrogate pair at their character bounds ([#1984](https://github.com/ThinkFlowLab/FlyBot/issues/1984)): a failed turn's 500-unit message, the 200-unit message of its one-line reason, the 79-unit step a running call shows, an approval card's 300-unit description and 400-unit command, and the 160-unit reason a failed turn leaves for the inbox now cut on a code point boundary, so a line that ends on an emoji keeps the whole emoji instead of an unpaired half the encoder turns into U+FFFD.
