A Workflow run whose host call never answered no longer stays running for ever: a step whose deadline passes is ended as failed even while a dispatch, a release or a Bot start is still waiting, with its Bots released. A start whose Bots the host does not create within 60 seconds is refused, and a queued card a drain had already taken out of the queue goes back to it instead of disappearing.
