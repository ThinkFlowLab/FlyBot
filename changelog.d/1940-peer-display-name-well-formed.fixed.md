A peer's display name is now made well formed before it is cleaned: when a roster name, an owner or lead label, an inviter name or a face seat arrives with half of a surrogate pair — a string JSON accepts but that is not well formed — the label carries the replacement character instead of a lone half that shows as an empty box and does not survive a UTF-8 round trip. The 60-character name bound and its code-point boundaries are unchanged, so a name that is already well formed comes back exactly as it was ([#1940](https://github.com/ThinkFlowLab/FlyBot/issues/1940)).
