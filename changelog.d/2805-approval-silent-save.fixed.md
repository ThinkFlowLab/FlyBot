A standing approval or a board claim is now refused when the store wrote nothing, instead of reporting success: in a read-only window (another dsh holds the store) or a stopped host, an **Always allow** answers with the store's read-only sentence and keeps no grant the file does not hold, `standing-approval-remove` keeps a grant whose removal was not written, and a claimed card rolls back to its queued state without posting the claim line, while Allow once and Reject still answer in a read-only window because they write nothing. See [#2805](https://github.com/ThinkFlowLab/FlyBot/issues/2805).
