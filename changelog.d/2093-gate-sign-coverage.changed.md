The gate signature now covers the queue gates it enforces: a pull request that changes `.github/scripts/enqueue-guard.mjs` or `.github/scripts/enqueue-rules.mjs` must carry a `Policy-sign:` line naming a comment by someone other than its author, and that comment must name the head, exactly as a change to `merge-gate.mjs` already did — a pull request can no longer loosen what may enter the merge queue without a second person's signature ([#2093](https://github.com/ThinkFlowLab/FlyBot/issues/2093)).
