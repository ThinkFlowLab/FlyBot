With the Project plugin switched off — or with `@flybot/project` not installed — the browser now shows no Project surface at all: no **Projects** row in the sidebar, no **Projects** page in Settings (a link that asks for it lands on General instead), no `#project=<id>` board, and no project-agent entry in a Bot's header. `plugins/list` now also answers whether each feature plugin really attached on this start (`loaded`), so "on but absent" is no longer indistinguishable from "installed and on"; the switch itself keeps its meaning and Settings → Plugins is unchanged. When the plugin is present every surface is exactly what it was. See [#2877](https://github.com/ThinkFlowLab/FlyBot/issues/2877).
