A Condition link that cannot be honoured is now refused instead of saved as a plain Link: a blank output name, or one the graph will not accept (`result_ok`, `ready.now`, `with space`), names the reason in the Settings alert and writes nothing, where it used to land as an unconditional edge that fired whether or not the condition held. Settings keeps **Add link** disabled for a Condition until an output name is typed, and a loop's `until` follows the same rule — absent still means no early stop, a partially filled one is refused ([#2155](https://github.com/ThinkFlowLab/FlyBot/issues/2155)).
