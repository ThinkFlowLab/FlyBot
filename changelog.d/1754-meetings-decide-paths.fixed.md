The `meeting` tool archives a decision that lists the cards it produced: the file now carries `- Tasks:` with the produced ids in order, every produced task is pre-flighted before anything is written (a refused or unauthorized task leaves no card, no temp file and no decision file behind), the day's second decision takes the next free name (`…-2.md`) instead of refusing `exists`, and a blocked meeting can be resumed with an answer and then decided, while a decided one stays closed ([#1754](https://github.com/ThinkFlowLab/FlyBot/issues/1754)).
