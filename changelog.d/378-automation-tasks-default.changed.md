Settings → Scheduled tasks works out of the box: the first time FlyBot runs in a DSH profile it switches on DSH's Automation tasks bundle (`@deepseek-ai/dsh-experimental-schedule-bundle`) through the plugin manager, once per profile, so a person who switches it off on the Plugins page keeps it off (`automationTasks: false` in the `bot` config opts out). When it is off, the hint now reads "Switch on Automation tasks on the Plugins page." and its button opens the Plugins panel instead of a Harness settings dialog that has no such switch ([#378](https://github.com/ThinkFlowLab/FlyBot/issues/378)).
