A busy Bot acknowledges a person's line once, not twice: the line id ledger that keeps one line from earning a second model call now outlives the ack entry, which the end of the turn clears, and is bounded — its fixed-size filter is rebuilt before it saturates, so a long-lived chat keeps getting acknowledgments ([#1684](https://github.com/ThinkFlowLab/FlyBot/issues/1684)). A person's line sent to a member that is speaking in a room is acknowledged at arrival too, instead of waiting for the claim the relay never makes ([#1646](https://github.com/ThinkFlowLab/FlyBot/issues/1646), [#1678](https://github.com/ThinkFlowLab/FlyBot/issues/1678)).
