`X-Sig`, `X-Hmac` and `X-Pass` values in a diagnostics log line or report row are masked now: the name list `cleanText` uses for the report and the downloaded log (`CREDENTIALS` in `core/src/host/diagnostics.js`) had none of the three, so a warning or log line that echoed one of those headers kept the value verbatim while `capabilities.js` already masked it in a stored capability body. `sig` and `pass` count as a whole segment, the way `pat` does there, so `assign`, `compass` and `bypass` keep their text; `hmac` is not part of any ordinary word. The value is masked from six characters, with a quote allowed on either side, so a JSON body is covered too, and a five-character value is left alone rather than eating the words around it ([#3291](https://github.com/ThinkFlowLab/FlyBot/issues/3291)).
