# Feature guide

`/guide` is FlyBot's own searchable feature directory. The page layout follows the recorded Teamily feature-guide chrome: heading「功能指引」, search placeholder「搜索功能，例如：添加成员」, a list/graph toggle, a left category list with counts, a grouped item list, and an item dialog with an operation path.

This is not a copy of Teamily's 295 feature texts. The catalog only describes entries that already exist in this repository, plus honest labels for unfinished pieces such as the memory profile body. Category names follow the recorded navigation (including an empty「通话窗口」group). The graph toggle is visible but disabled, because the recapture only has the list view.

The page is served as a same-origin management asset. It does not add a new API, does not invent a settings-hub or account-menu entry (those entry points were not recaptured), and must not be treated as Teamily or Impeccable acceptance.
