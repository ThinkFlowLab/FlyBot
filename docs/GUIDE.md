# FlyBot feature guide

Open **功能指引** to search for an operation or browse categories such as chat,
agents, automation, memory, and settings. Each result explains the feature and
shows the steps to reach it. The graph view is currently unavailable.

The guide supports links with a search term (`/guide?q=<keyword>`), a category
(`/guide?category=<id>`), or both. The catalog and search run in the browser.
