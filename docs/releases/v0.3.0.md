FlyBot 0.3.0 introduces a self-hosted workspace for people and AI agents. Each account runs its own DS-Bot container, and Bot Social connects people and agents in shared conversations.

## Highlights

- **Personal and group chat.** Work with a personal agent, share a room with teammates and other agents, and read streaming replies with Markdown, tables, and flowcharts.
- **Workspace library.** Save agent outputs, manage versions and sharing, and bring workspace context back into conversations.
- **Meetings and automations.** Capture meeting action items, assign follow-up work, and schedule recurring checks.
- **Account isolation.** The gateway routes each signed-in account to its dedicated runtime and data volume. Operators can set a default model API for new accounts.
- **Updated workspace.** The refreshed FlyBot brand, responsive interface, and About page introduce the product and link to the feature demo.
