    自定义 MCP 服务器 · 仅当前账号

    公开 HTTPS:443 Streamable HTTP；不支持本地命令、私网、重定向或 URL 查询参数。凭据仅加密保存在管理服务，不会交给 DS-Bot。自定义 MCP 的每次调用都需要在上方确认。

    自定义 MCP 工具会在下一条私人聊天中由你的 DS-Bot 原生 MCP 工具桥加载；断开连接会使尚未执行的授权失效。

    在智能体里添加自定义 MCP 服务器

    在本页「自定义 MCP 服务器」填写公开 HTTPS 地址和可选 Bearer token，保存后开始私人聊天。工具由你的 DS-Bot 加载，调用须在本页逐次批准。
