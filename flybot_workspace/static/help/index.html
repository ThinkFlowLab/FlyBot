会话

现在能做什么

  • 单聊与群聊在同一个聊天页（/chat），左侧会话列表、右侧消息流，工作区用列表顶部的选择器切换。
  • 发文字消息和图片附件。图片在消息流里直接渲染成图片（点击可看原图），不是文档卡；附件在发送前就写进当前工作区的作品库，按「媒体」类型可查。
  • 会话内搜索：输入关键词后点命中项，会跳到那条消息。
  • 发送快捷键是 Ctrl+Enter（macOS 为 ⌘+Enter），单独 Enter 只换行。

已知边界

  • 输入框工具栏里的 Auto / Instant / Agentic 模式、格式工具、表情、技能、会议纪要、用记忆强化提示都还是 disabled 占位，点了没有反应。
  • 没有语音或视频通话入口。

Agent 渠道

可以通过站内聊天使用智能体，或在智能体页为外部调用创建 Agent API 密钥。下列渠道目前没有站内授权入口。

微信公众号

需要独立的渠道服务处理公众号消息的校验、接收和回复。

Apple iMessage

需要能收发 iMessage 的外部渠道服务。

Slack

需要部署 Slack 应用和接收工作区消息的回调服务。

WhatsApp

需要能接收并发送 WhatsApp Business 消息的外部渠道服务。

智能体

现在能做什么

  • 在 /agents 创建和编辑智能体：名字、说明、运行时与模型，列表里显示每个智能体当前的运行时状态。
  • 公共目录按分类浏览（/agents?category=…），分类链接可以直接分享。
  • /skills 里安装技能，安装记录按账号保存，刷新后仍在。

已知边界

  • 平台不提供由平台托管的云端计算机，也不托管云端 Agent（/runtimes 页原话）；智能体连的是你自己配置的运行时。
  • 公共目录没有「创建者」字段，所以没有按作者筛选。

作品库

现在能做什么

  • 作品分六类：文档、网站、幻灯片、仪表盘、白板、媒体（/artifacts 的「新建」是 /artifacts?new=<kind>）。
  • 收藏、版本历史、导出和分享都有真实接口：单件导出是 GET /v1/workspaces/<workspace>/artifacts/<id>/export，历史版本导出是同一路径下的 /versions/<n>/export。
  • 聊天里发的图片作为「媒体」作品出现在同一个作品库；空态里的「保存聊天中的图片」按钮会把你带到聊天页。

已知边界

  • 作品库空态里还有两个 disabled 占位入口：从已完成任务保存智能体成果、从作品库让智能体搭网站——对应接口还没合入这个实例。
  • 没有账号级的「一次性导出全部作品」按钮，导出按单件（或单件的某个历史版本）进行。

自动化

现在能做什么

  • 在 /automations 按模板建自动化，模板会预填提示词。
  • 运行记录可以按「全部 / 成功 / 失败」筛选，筛选条件写在地址栏（/automations?run=…），刷新后保留。
  • 每次运行都会在当前工作区留下一条运行记录和对应产物。

已知边界

  • 自动化只在本实例配置的模型 API 上跑，不代管外部账号，也没有第三方触发器（例如日历或邮箱事件）。
  • 模板列表只包含实例里真实存在的模板；template=custom 不是可分享的模板链接。

会议

现在能做什么

  • 在 /meetings 新建会议、写纪要、列行动项（负责人、截止日期、备注），整份会议一起保存。
  • 会议列表按工作区隔离，刷新后仍在。

已知边界

  • 没有录音、自动转写或日历邀请：纪要和行动项都是手写的。
  • 会议内容不会自动发到群里，要分享请复制会议页链接。

记忆

现在能做什么

  • /memory 有「记忆页」和「下一步行动」两个视图（?page=profile / ?page=todos），可以直接新建、编辑、删除。
  • 删除记忆页或下一步行动前会先问一句，取消不会发出请求。

已知边界

  • 「整理记忆」（对照里的「做梦」）和分享记忆页都还是 disabled 占位，对应接口没接通。
  • 记忆只影响你自己在这个实例里的视图，不会自动进入聊天上下文。

团队

现在能做什么

  • 在 /team 创建团队并绑定工作区，分三步走：团队信息、成员、角色说明与逐行邀请。
  • 在 /members 邀请成员、冻结或撤销邀请、移除成员；移除和撤销前会先显示行内确认。

已知边界

  • 没有 SSO、域名验证或自动加入；成员靠邀请。
  • 团队与工作区的权限按实例里的成员表计算，没有更细的自定义角色编辑器。

运行时

现在能做什么

  • /runtimes 连接你本机的运行时，页面显示连接状态和最近心跳。
  • 给运行时生成 API key 并撤销；新生成的密钥会进入列表，撤销后立即失效。

已知边界

  • 平台不提供托管的云端计算机，也不托管云端 Agent；运行时进程要你自己起。
  • 密钥只在生成时显示一次明文，之后列表里只有名字和状态。
