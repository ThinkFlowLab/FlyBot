隐私政策

说明这个自托管实例把数据放在哪、谁能读到、怎么导出、怎么删除。所有路径都对着实例里真实的目录和接口写。

数据落在哪

  • 全部应用数据在一个 SQLite 数据库里：启动参数 --data-dir 指向的目录下的 management.sqlite3。目录和文件权限是 0700 / 0600，要求属主是运行进程的用户。
  • 作品与头像的媒体字节存在 --data-dir 下的 artifact-objects/<工作区 ID>/<sha256>（目录 0700、文件 0600，按内容寻址），数据库里只记 sha256、MIME 与字节数（artifact_media、user_avatars 表）；没有外部对象存储，也没有 CDN。
  • 页面静态资源随代码发布，不含用户数据。

存了什么

  • 账号：用户名、密码哈希、注册时间；登录后是会话 Cookie。
  • 资料：昵称、FlyBot ID、简介、标签、性别、所在地、网站、人生目标、头像；人生目标标记为仅自己可见。
  • 内容：会话消息与附件、作品及其版本、自动化运行记录、会议与行动项、记忆页与下一步行动、团队与成员关系、邀请。
  • 运行：运行时名称、连接状态与心跳、API key 的哈希（明文只在生成时显示一次）。

谁能看到

  • 应用内按工作区和团队权限隔离：不是成员就看不到该工作区的会话、作品和会议。
  • 公开的东西只有你主动公开的部分：/p/<handle> 公开资料页、公开作品页、公共目录里的智能体。
  • 实例运行者在文件层面能读整个数据库；这是自托管的固有边界，不是应用 bug。

Cookie

  • 只用于登录会话与 CSRF 校验。生产模式下名字带 __Host-ot_ 前缀，本地不安全模式（--insecure-local）用 ot_dev_ 前缀。
  • 没有广告或第三方统计 Cookie，页面也不加载外部脚本。

外部服务

智能体和自动化的模型请求会发到实例运行者配置的模型 API（/settings 里的 model API 设置）。聊天内容因此会经过那个服务；换服务商或断开配置由运行者决定。除此之外应用不主动向外发数据。

导出

  • 作品可以逐件导出：GET /v1/workspaces/<workspace>/artifacts/<id>/export，历史版本是 …/versions/<n>/export；导出文件直接下载。
  • 目前没有账号级的「导出全部数据」按钮。要整库备份，由运行者复制 management.sqlite3。

删除

  • 作品、记忆页、下一步行动、会议、自动化和团队成员都可以在界面里删除，删除前有确认。
  • 删除账户：资料页的「删除账户」按钮仍是 disabled 占位，这个版本没有自助删除路由。需要删账号时找实例运行者，他会从数据库里清掉你的记录。
  • 运行者删除 --data-dir 整个目录，就等于删掉这个实例的全部数据；删除后无法恢复，没有回收站。

日志

应用只往启动它的进程的标准输出和标准错误写日志，是否落盘、保留多久由运行者决定。应用本身不另建日志文件，也不把消息正文写进日志。

想确认某条数据在哪：数据库是单个 SQLite 文件，可以直接用只读方式打开查看表结构；改数据请先备份。
